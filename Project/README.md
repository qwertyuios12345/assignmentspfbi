# Congressional Trade Performance Analysis

This folder contains the course project notebook and supporting data files.

The project analyzes disclosed U.S. congressional stock trades from 2023 and compares their 30-day and 90-day performance against the S&P 500.

## Files

- `congressional_trade_analysis.ipynb` - main Jupyter Notebook
- `Data files/` - raw CSV files used in the project
- `Processed data/` - exported raw/processed data from the notebook
- `Results/` - exported analysis results

## API key

The notebook uses the Gemini API for the AI analysis section. The API key should be stored locally in a `.env` file:

```text
GEMINI_API_KEY=your_key_here

```markdown
The `.env` file should not be uploaded to GitHub.
